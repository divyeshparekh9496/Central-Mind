For grown-ups: voice, learning & privacy

Voice is optional and starts only when you press the microphone. Your browser’s speech provider may process audio online. This app does not save raw audio, names or free-form voice transcripts in its adventure progress database. Progress uses a random session ID and stays on this server until deleted. The offline guide uses a small NASA-linked fact collection reviewed October 17, 2026; it is not a live web search. Quiz difficulty uses Bayesian Knowledge Tracing with configured, not fitted, parameters.
